# security_expert knowledge
- idea_06 Zero-trust agent mesh: AGNTCY SLIM already provides authenticated, encrypted group messaging with per-agent identity, so per-message authorization can reuse it. Realistic as a policy layer on top; a prototype in about 12h is credible. Latency overhead is small if policy is cached.
- idea_02 Quantum-safe overlay: NIST finalized ML-KEM and ML-DSA; mature open-source implementations exist. A software-only hybrid key exchange is buildable now; hardware offload is the only missing piece and is not needed for a prototype.
- idea_01 Agent identity wallets: W3C verifiable credentials and DIDs are stable standards; open-source wallets already exist, so a differentiator would have to be agent-specific delegation.
- idea_09 Federated threat intel: secure aggregation is well studied but needs a coordinator and careful privacy budgets; hard to demo in 40h.
- idea_08 Photonic telemetry: not a security topic; no knowledge.
