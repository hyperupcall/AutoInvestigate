# Legacy: idea-negotiation council (Part 1)

The original 4-agent negotiation over 10 fixed ideas (3-of-4 tally, expert agents, eval, live UI),
archived when the project was reworked into idea evaluation. It still runs on its own:

    cd legacy && make up        # UI at http://localhost:8090
    make down

Don't run it at the same time as the new system (same ports). See README.md in this folder's
git history for the full description.
